## 1. Резюме

**Стратегия [В].**
- Сначала берём взрослых 18+ (новички, возвращающиеся; CCM, поп, мюзикл). Начинаем со студентов самой школы VF, затем идём в US онлайн через бесплатный Voice Snapshot.
- Продаём не приложение и не балл. Продаём живого педагога, чей урок работает всю неделю: домашка с голосовым ответом и слышимая пара Before/Now.
- Индивидуальный педагог (Founding Coach) — дешёвая параллельная проверка B2B. Школам ничего не строим до ворот №4.
- Боль доказана на уровне A (TAL/START, STAGE, эталон ↔ попытка: S1, S4, S5, S11, S36). Готовность платить — C/D. Связь «слышимый прогресс → удержание» — D, это главная бизнес-гипотеза (H2).

**Экономика Snapshot (финдиректор, после правки R3) [В/Д]**
- При конверсиях 15% (Snapshot → диагностика) и 30% (диагностика → Starter) на одного покупателя Starter уходит ≈22 Snapshot.
- При 5–8 мин на Snapshot это $75–120 времени педагога ($40/ч). Валовая маржа Starter ≈$50–90. **Правило 4.3 нарушено.**
- Исправление:
  - шаблонный ответ, медиана **≤4 мин** — это ≈$60 на покупателя;
  - Snapshot доступен только тем, кто видел цену и оставил контакт;
  - параллельный вход через платную диагностику.
- Если медиана >4 мин или стоимость Snapshot на покупателя выше маржи первого месяца, Snapshot закрываем как вход.
- **Резерв на возвраты по гарантии — 10% выручки Starter [Д]** (правка Red team 9.2 №9).
- Выручку Founding Coaches в финплан на 6 мес. не закладываем.

### 4.4 North Star и защитные метрики

**North Star.**
- **Месяцы 0–3 — Weekly Coached Recorders (WCR):** число студентов, у которых за неделю есть ≥1 домашняя запись и ≥1 ответ педагога, утверждённый через AI Gate.
- **С месяца 3 — Weekly Coached Practisers (WCP):** то же, но с ≥2 днями практики. Дни практики — самоотчёт одной кнопкой в чек-ине VF-045, пока нет приложения (правка R7).
- Недели с «I'm sick» исключаются из знаменателя (правка методиста, WHS §2.5).
- Почему дни практики: они отличают бросивших (S28, A для инструментов, перенос на вокал — B). Активность за прогресс не выдаём (VF-043).

| Защитная метрика | Порог | ID |
|---|---|---|
| Безопасность: пение после «hurts»; клипы домой без флага «можно петь дома» или выше верха урока | 0; аудит 100% заданий | VF-030 |
| Флаг здоровья → ответ педагога и refer-out | В тот же день, 100% | VF-030, VF-065 |

## 10. Как обновлять документ

| Правило | Суть |
|---|---|
| Когда | После каждой волны данных (интервью, опрос, пилот): нед. 2, нед. 8, мес. 3, мес. 6. Перезапуск по `prompts/master-product-synthesis.md` §7 |
| Источник истины по ID | `voice-family-backlog.csv`. Новые решения получают следующий VF-ID; старые ID не переиспользуем; удалённые помечаем категорией «Не делаем» с причиной |
| Доказательства | Каждое изменение — со ссылкой на файл и ID и с пометкой [Ф]/[В]/[Д]. При переводе [Д] → [Ф] указываем, откуда данные (хронометраж, интервью №, когорта) |
| Надёжность | Только по §3. Совпадения VT↔SPR и VT↔TP — один источник. Данные пилота с n<30 — не выше B и с пометкой n |
| Противоречия | Только через новую строку таблицы раздела 3 (№37+). Молча не меняем |
| Пороги | Меняем только до начала замера, а не после. Фиксируем в журнале версий |
| Мощность | Любое добавление в этап — с пересчётом дней разработчика и часов методиста и указанием, что выкидываем |
| Ограничения | Безопасность голоса, приватность, 18+, AI Gate и ≤20 мин педагога не пересматриваются ради метрик |
| Объём | ≤6 000 слов; детали — в приложения и CSV |
| Журнал версий | В конце документа: дата, что изменилось, какие данные. Текущая: v1.0, 2026-09-26, первая сборка + правки Red team и методиста |
