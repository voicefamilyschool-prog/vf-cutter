# Промт: анализ целевой аудитории по всем открытым источникам

> Используется Workflow «Аудитория: открытые источники». Дополняет ресёрч по Reddit (`reports/*-pains-report.md`) и научные исследования (`reports/academic-studies-report.md`). Рынок — англоязычные страны.

---

## Цель

Пройти по всем доступным открытым источникам и собрать **боли, желания, страхи, триггеры покупки и готовность платить** нашей целевой аудитории. По каждому сегменту — вывод и **5 доступных решений** для Voice Family.

## Сегменты

1. **Студенты:** взрослые новички и любители; будущие профессионалы (мюзикл, классика, поп); родители детей-вокалистов.
2. **Частные педагоги вокала** (voice teachers / singing teachers / vocal coaches).
3. **Владельцы музыкальных школ и студий** с вокальным отделением.

## Источники и инструменты (проверено, что работает)

| Источник | Как | Что даёт |
|---|---|---|
| Отзывы Google Play | `python3 tools/open_sources.py gplay "<запрос>"` → пакеты; `python3 tools/open_sources.py playreviews <package> n=150 sort=newest|relevant maxstars=5` | Боли и желания пользователей приложений: за что платят, почему удаляют |
| Подсказки поиска Google | `python3 tools/open_sources.py suggest "<seed>" expand=1` | Формулировки и реальные запросы: страхи, желания, вопросы |
| Поиск YouTube (названия, каналы, просмотры) | `python3 tools/open_sources.py ytsearch "<запрос>" limit=20` | Какой контент нужен аудитории: популярность тем по просмотрам |
| Wayback Machine | `python3 tools/open_sources.py wayback <url> <год>` + WebFetch снимка | Как конкуренты меняли обещания и цены |
| Веб | WebSearch / WebFetch (загрузить через ToolSearch) | Trustpilot / Sitejabber / Quora (через поиск), лендинги и цены конкурентов, цены уроков по странам, отраслевая статистика |
| Reddit | `python3 tools/reddit_rss.py …` | Только для точечной проверки — основной сбор уже сделан |

Недоступно из облака: отзывы App Store (лента пустая), комментарии YouTube (капча), прямой доступ к Trustpilot, Quora, Meta Ad Library, Indeed, BLS — пробовать только через WebSearch/WebFetch.

## Правила

- Только реальные цитаты и данные с источником. Ничего не выдумывать.
- Каждую запись помечать: сегмент, тип (**боль / желание / страх / триггер покупки / готовность платить / возражение**), сила 1–3, источник, дата.
- Для подсказок поиска и YouTube — фиксировать формулировку и сигнал спроса (просмотры, порядок подсказки), а не цитату.

## Анализ по каждому сегменту

1. Боли, желания, страхи, триггеры покупки, возражения — с частотой по источникам.
2. Язык аудитории (дословные формулировки).
3. Что новое по сравнению с нашими прошлыми отчётами (`reports/`), что подтверждается, что противоречит.
4. **5 доступных решений**: что делаем (фича, контент, оффер, позиционирование, процесс), какую боль/желание/страх закрывает, на что опирается из уже спроектированного, стоимость и срок (дёшево, 1–4 недели), как проверить (метрика).

## Результат

Отчёт на русском (цитаты и формулировки — на английском): резюме; по каждому сегменту — анализ и 5 решений; общие для сегментов выводы; карта источников (что дал каждый источник); ограничения; приложение — все записи.
