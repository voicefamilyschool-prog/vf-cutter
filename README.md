# Voice Family — сервис нарезки

Режет запись занятия на короткие фрагменты по таймкодам. Нужен потому, что n8n сам работать с аудио не умеет — внутри этого сервиса стоит ffmpeg.

## Как развернуть на Railway

**1. Положить файлы в GitHub**

Создайте новый репозиторий `vf-cutter`. Через кнопку **Add file → Upload files** закиньте туда четыре файла: `main.py`, `Dockerfile`, `requirements.txt`, `README.md`.

**2. Развернуть**

В Railway откройте тот же проект, где живёт n8n → **+ New** → **GitHub Repo** → выберите `vf-cutter`.

Railway увидит Dockerfile и соберёт образ сам. Первая сборка идёт минуты три: ffmpeg весит прилично.

**3. Придумать ключ**

В настройках сервиса → **Variables** → добавьте переменную:

```
CUT_API_KEY = придумайте_длинную_строку
```

Без неё сервис будет открыт для всех, кто узнает адрес.

**4. Получить адрес**

**Settings** → **Networking** → **Generate Domain**. Появится адрес вида `vf-cutter-production-xxxx.up.railway.app`.

**5. Проверить**

Откройте адрес в браузере. Должно ответить:

```json
{"status": "ok", "service": "Voice Family Cutter"}
```

Значит работает. Пришлите адрес — подключу к воркфлоу разбора.

## Что сервис делает

Принимает запись и список моментов, возвращает нарезанные mp3.

Каждый фрагмент начинается **за 55 секунд до указанного момента** — чтобы в него попало и само исполнение, и разбор педагога после него. Длина по умолчанию 80 секунд, меняется отдельным параметром.

Имена файлов формируются сразу в нужном виде:

```
1. 02-35 — Не давлю, место раскрывается.mp3
```

## Ограничения

- До 20 фрагментов за раз
- Длина одного фрагмента от 5 до 300 секунд
- Файлы нигде не сохраняются: сервис режет и сразу забывает
